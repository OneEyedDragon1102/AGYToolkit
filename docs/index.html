Operator Playbook & Usage Guidelines

Standard operating procedures for managing, scaffolding, and running autonomous agent teams with AGYToolkit.

1. Machine-Wide Installation & Global Mounting

Mount all 28 skills and 15 agents into your global Antigravity config directory (~/.gemini/config/) so any workspace opened in AGY automatically discovers them:

agy-toolkit link-global

Use agy-toolkit link-global --dry-run to preview symlinks and copied blueprints before writing.

2. Scaffolding Governance into Downstream Projects

Provision the complete .agents/ runtime, memory system, lifecycle hooks, and project rules into any target repository:

agy-toolkit init ../my-service --name order-service --stack spring-boot --mode feature

Supported stacks: spring-boot (Java 23), node-ts (Node 20), python (Python 3.12). Modes: feature, spike, quickfix.

3. Non-Destructive Downstream Synchronization

Pull the latest skills, agents, and lifecycle hooks into an existing downstream repository while strictly preserving your local rules and session memory:

agy-toolkit update ../my-service

Add --dry-run to preview planned changes, or --force-rules to refresh customized rules from blueprints.

4. Dual-Tier Memory & Dynamic Auto-Compaction

The memory engine prevents token exhaustion and amnesia by enforcing hard byte ceilings (1 KB for working context, 3 KB for architectural decisions). When approaching 85% capacity, auto-compaction triggers automatically via PostToolUse hooks:

# Trigger manual auto-compaction agy-toolkit memory auto-compact # Preview compaction projections without writing agy-toolkit memory auto-compact --dry-run # Output metrics in JSON format agy-toolkit memory status --json

5. Multi-Agent Volatile IPC Event Bus Operations

Agents pass structured messages and claim tasks through the volatile event bus without polluting conversational context:

# Publish an event envelope agy-toolkit bus send --topic review --sender code-reviewer --recipient orchestrator --payload '{"status": "PASS"}' # Stream events in real time agy-toolkit bus watch --topic review --timeout 30

6. Native Antigravity MCP Server Integration

Expose diagnostics, memory budgets, and event bus streaming directly to your Antigravity IDE agent by registering the MCP server in ~/.gemini/antigravity.json:

{ "mcpServers": { "agy-toolkit": { "command": "agy-toolkit", "args": ["mcp"] } } }
